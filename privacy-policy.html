Route Exporter

Privacy Policy

Effective and last updated: October 20, 2026

Route Exporter processes route information locally in your browser to create the GPX file you request. The developer does not receive, store, sell, or share this information.

About the extension

Route Exporter is a browser extension that exports the route currently selected in Google Maps at www.google.com/maps/ or www.google.pl/maps/, HOGS Maps at app.hogs.live, IMPARGO at apps.impargo.de, or Webfleet at live-wf.webfleet.com as a standards-compliant GPX file.

Information processed

To provide its export function, the extension processes:

  • the selected route geometry;
  • ordered route stops, dragged via points, and location coordinates;
  • the selected route name used for the downloaded filename;
  • website content required to identify and assemble the active route.

This processing is limited to the route information needed for the export requested by the user. The extension does not collect authentication credentials, payment information, personal communications, health information, browsing history, or advertising identifiers.

How information is used

Route information is used only to identify the active route, preserve its stop order and name, and generate a GPX file for download. It is not used for advertising, profiling, analytics, creditworthiness, lending, or any purpose unrelated to route export.

Local processing and retention

Processing and GPX generation take place entirely within the user's browser. Route information is not sent to the developer's servers and is not stored by the extension after processing. A downloaded GPX file remains on the user's device and under the user's control until the user moves or deletes it.

Sharing and sale of information

The developer does not sell, rent, disclose, or transfer route information or other user data to advertisers, analytics providers, data brokers, or any other third party.

Permissions

The extension requests access only to https://www.google.com/maps/*, https://www.google.pl/maps/*, https://app.hogs.live/*, https://apps.impargo.de/*, and https://live-wf.webfleet.com/*. This permission is required to read the active route, route name, and ordered stops displayed in a supported route planner, detect route changes, and make the resulting coordinates available for the local GPX download. On Google Maps, it reads loaded directions data and observes directions responses already requested by the page; it does not initiate network requests or read request headers or authentication tokens. The extension does not request access to other websites.

Remote code and external services

All executable extension code is included in the installed extension package. The extension does not download or execute remotely hosted code, and it does not use external analytics, advertising, tracking, or file-conversion services.

Chrome Web Store Limited Use

The extension's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide the extension's single, user-facing route-export purpose.

User choices

Users can stop all extension processing by disabling or uninstalling Route Exporter. Because the developer does not receive or retain route information, there is no server-side user record to access, correct, or delete. Users can delete exported GPX files directly from their devices.

Children's privacy

The extension is not directed to children and does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated if the extension's functionality, data practices, or legal requirements change. The current version will remain available at this URL with its effective date shown above.
